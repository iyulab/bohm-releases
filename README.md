# Bohm — Downloads

Bohm is a desktop browser for the small web apps you make with AI: add an HTML file, and it runs as an
app on your PC, with its data kept on your PC. It works without an internet connection.

## Download

[Latest release](https://github.com/iyulab/bohm-releases/releases/latest) — `Bohm_<version>_x64-setup.exe`

## System requirements

- Windows 10 or 11 (x64)
- No administrator rights needed — Bohm installs for the current user.
- No internet connection needed to install. The installer carries the Microsoft Edge WebView2 Runtime
  and installs it only if the PC does not have it.
